Entry for [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) on make.fun.

The program writes one two-part micro-confession to `/output/entry.txt`: a `To:` line naming who the message was meant for, and the unsent message itself, one line written exactly as it was typed, with no explanation after it. Total length is 97 characters, inside the 1–260 character gate.

Run: `node main.ts`
